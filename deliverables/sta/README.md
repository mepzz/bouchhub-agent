# Stage Engine Deliverable

Contains the implementation of the pluggable staging engine.

## Structure
- `src/stage/`: The core logic.
  - `Provider.ts`: The interface.
  - `LocalStub.ts`: The local generator (no API spend).
  - `ApiAdapter.ts`: Ready but never used.
- `styles/`: Prompt packs.
- `deliverables/sta/outputs/`: Generated output location.
